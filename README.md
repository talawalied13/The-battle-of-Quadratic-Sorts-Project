# The-battle-of-Quadratic-Sorts-Project
The Battle of Quadratic Sorts
A computer science course project comparing the performance of quadratic sorting algorithms.
Course: Computer Science, Sorbonne University Abu Dhabi
Type: Group project (Group 9, Topic 4)
Overview
This project examines and compares quadratic-time sorting algorithms (such as bubble sort, insertion sort, and selection sort), looking at how they behave on different inputs and how their running times compare in practice.
Contents
The report is written in LaTeX and covers the algorithms studied, the comparison method used, and the results.
